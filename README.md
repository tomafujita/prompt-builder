# プロンプトビルダー（デモ版）

チェック項目を埋めるだけで、AIに伝わるプロンプトが完成する Web アプリです（ゼミ発表用のデモ版）。

- HTML・CSS・JavaScript だけで動きます（インストール不要・ネット接続も不要）
- 入力した内容は保存されません（再読み込みすると消えます）

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く
2. **① やりたいこと** に、AIにやってほしいことを一文で書く
3. **② 用途を選ぶ** で「レポート」「要約」「ES添削」から近いものを選ぶ
   - 入力欄の薄い文字（入力例）が、その用途の例に変わります
   - 「例を全部入れる」を押すと、例文がすべて入ります（発表のデモ用）
4. **③ チェック項目** を埋める（空欄があってもOK）
   - 各項目の「例を入れる」で、その項目だけ例文を入れられます
   - 項目の下の「なぜ必要？」がヒントです
5. 右側（スマホでは下）に、完成したプロンプト（After）と充実度スコアが出ます
6. 「コピー」を押して、「ChatGPTを開く」などからAIに貼り付ける

「リセット」を押すと、入力をすべて消せます。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `app.js` | プロンプトの組み立て・スコア・コピーなどの処理 |
| `templates.js` | 例文・ヒント・アドバイスなどの**文言（班員が編集する）** |
| `SPEC.md` | 仕様書 |

### 文言を変えたいとき

`templates.js` だけを編集してください。ファイルの先頭に書き換えのルールが書いてあります。
保存したら、ブラウザで再読み込みすると反映されます。

## GitHub Pages で公開する手順

1. GitHub でこのリポジトリ（`prompt-builder`）のページを開く
2. 上のタブの **Settings** を押す
3. 左のメニューの **Pages** を押す
4. **Build and deployment** の **Source** を「**Deploy from a branch**」にする
5. **Branch** を「**main**」、フォルダを「**/ (root)**」にして **Save** を押す
6. 1〜2分待ってから Pages の画面を再読み込みすると、上に公開URLが出る
   - URL の形：`https://<GitHubのユーザー名>.github.io/prompt-builder/`

その後は、main ブランチに push するたびに、数分で公開ページも更新されます。

> 注意：リポジトリが Private（非公開）の場合、無料プランでは GitHub Pages を使えません。
> Settings → General の一番下「Danger Zone」で Public に変えるか、有料プランが必要です。
